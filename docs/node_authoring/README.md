# Node authoring
Declare metadata in `src/nodes/catalog.ts` (type, version, category, displayName, description, fields → config schema, inputs, outputs, sourceHandles, defaultTimeoutMs, defaultRetryPolicy, requiredCapabilities, sensitiveFields, sideEffectLevel, supportsCancellation/Retry). Implement `(ctx) => Promise<NodeResult>` in `src/nodes/impl.ts` using only the `NodeRunContext` surface: `ctx.page()`, `ctx.locator()`, `ctx.artifacts`, `ctx.scope`, `ctx.notify`, `ctx.cancellation`. Runtime values (Page/Locator) go in `runtime`, JSON in `values`; secrets are flagged via `ctx.secretKeys` and must never be returned as values. Contract tests (`tests/contracts`) verify every catalog entry.
