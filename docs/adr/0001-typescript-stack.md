# ADR-0001: TypeScript end-to-end instead of Python/FastAPI
Context: the delivery sandbox is a Next.js + Drizzle + PostgreSQL platform without Docker and with Python 3.11 only. Decision: implement the control plane, worker and scheduler in TypeScript (Node 22) sharing one Flow schema/catalog across API, worker and editor, with Drizzle for schema management. Consequences: single language and single Zod schema (no duplicate front/back schemas); Alembic is replaced by drizzle-kit migrations; the process/deployment topology (api, scheduler, browser-worker, postgres) is unchanged.
