# BrowserFlow user guide (English)

1. Choose English or 中文 in the top bar.
2. Sign in as the administrator created by `browserflow admin create`.
3. Create a flow, drop nodes on the canvas, connect SUCCESS / TRUE / FALSE edges.
4. Save the draft (autosave also writes the draft).
5. Compile. Fix ERROR diagnostics before publishing.
6. Publish an immutable FlowVersion.
7. Run immediately or attach a schedule.
8. Open an execution to replay events, screenshots, and artifacts.
9. Store credentials as encrypted secrets and reference them with CredentialRef.
10. Identities keep a private Chromium profile; only one execution may lock an identity at a time.
