# Getting started
1. Initialise the administrator on first visit. 2. Add a **Credential** (e.g. `site-login` with `username`/`password`) and reference it as `credential:site-login#password` in an *Fill* node. 3. Create an **Identity** if you need a persistent browser profile and select it in Flow → Settings. 4. Build the flow: drag nodes from the palette, connect handles (colour = edge kind: SUCCESS, TRUE/FALSE, LOOP_BODY/LOOP_DONE, ERROR, FINALLY), bind inputs to upstream outputs or variables, use `{{variable}}` templates. 5. **Compile** to see diagnostics, **Publish** to create an immutable version, **Run ▶**. 6. Watch the execution: live event log (auto-reconnecting), node inputs/outputs, screenshots (after navigation, on failure, at the end, and every 3–5 s while *Live preview* is on), artifacts. 7. Create a **Schedule** (cron/one-shot, timezone, misfire/overlap policies).
