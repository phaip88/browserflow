# Roadmap
## Release 1 (this release) — production core
Auth, flows/drafts/immutable versions, schema + compiler, deterministic engine, persistent executions/attempts/nodes/events, state machine, independent worker with lease/heartbeat/recovery, timeout/cancel/retry, 42 nodes, Playwright Chromium, identities with exclusive locks, encrypted credentials + CredentialRef, local artifacts + safe paths, HTTP & browser network policy, persistent scheduler, transactional outbox + ordered events + SSE replay, visual editor, admin pages, Docker Compose, backup/restore/doctor/cleanup, tests & evidence.
## Release 2 — advanced workflows
Multi-page orchestration, popups, upload/download enhancements, switch/break/continue, waitForUserInput, data.map/filter, webhooks, advanced debugging, debug execution from a given node, S3/MinIO artifact adapter, more templates, 500-node editor optimisation, Human Takeover technical validation, Redis wake-up accelerator.
## Release 3 — AI & advanced debugging
Real AI providers, AI flow builder, AI repair, diagnostic explanations, breakpoints/step-over, human takeover, external BrowserProvider, external collector templates, session live streaming (noVNC).
